# Repositorio-Codigos-Tecnicas-Estadisticas-y-Analisis-de-Datos-Climaticos
Este repositorio contiene los códigos utilizados en el curso de Técnicas Estadísticas y Análisis de Datos Climáticos durante los semestres 2025-2 y 2026-1. Se enfoca en 4 fases: Análisis exploratorio de datos, Control de Calidad de datos, Completado de datos y Downscalling estadístico.
